# Delete profile buckets

- **Method:** `DELETE`
- **Path:** `/ns/{namespace}/profile/buckets`
- **Operation ID:** `deleteNsByNamespaceProfileBuckets`
- **Tags:** Profiles

Remove profile categories created specifically for this namespace. Unknown names are safely ignored, while organization-wide buckets remain protected.

## Effective servers

- `https://api.supermemory.ai`

  Production Server

## Authentication

- **bearerAuth**: HTTP bearer

## Path parameters

- **`namespace` (required)**: `string`, maxLength: `100`, pattern: `^[a-zA-Z0-9_:-]+$`

  The isolated namespace to search. This can be an ID for your user, a project ID, or any other identifier you wish to use to scope memories.

## Request body

**Required:** `true`

**Content type:** `application/json`

no additional properties

- **`buckets` (required)**: `array`, minItems: `1`, maxItems: `50`

  Namespace-owned bucket names to delete. Organization-level buckets are protected and cannot be removed here.

  **Items:**

  `string`, minLength: `1`, maxLength: `64`, pattern: `^[a-z0-9][a-z0-9_-]*$`

  Stable slug for the bucket, stored on each memory

**Example:**

```json
{
  "buckets": [
    "interests"
  ]
}
```
